## Variables ##

**Extracellular nanoparticle concentration (N)**<br>
Units: M (mol / L)<br>

**Available receptor concentration (R<sub>T</sub>)**<br>
Units: receptors / cell<br>

**Surface-bound nanoparticle-receptor complexes (B)**<br>
Units: complexes / cell<br>

**Internalised nanoparticles (I)**<br>
Units: particles / cell<br>

**Active intracellular payload (P)**<br>
Units: mol / cell<br>

**Senescent-cell population (S)**<br>
Units: cells<br>

## Parameters ##

**Binding rate constant (k<sub>on</sub>)**<br>
Units: M<sup>-1</sup>h<sup>-1</sup><br>

**Dissociation rate constant (k<sub>off</sub>)**<br>
Units: h<sup>-1</sup><br>

**First-order internalisation rate constant (k<sub>int</sub>)**<br>
Units: h<sup>-1</sup><br>

**Maximum internalisation rate (V<sub>max</sub>)**<br>
Units: particles / cell * h<br>

**Half-saturation constant for internalisation (K<sub>int</sub>)**<br>
Units: particles / cell<br>

**Intracellular nanoparticle clearance rate (k<sub>clear</sub>)**<br>
Units: h<sup>-1</sup><br>

**Intracellular payload release rate (k<sub>rel</sub>)**<br>
Units: h<sup>-1</sup><br>

**Intracellular active payload elimination rate (k<sub>e</sub>)**<br>
Units: h<sup>-1</sup><br>

**Maximum nanoparticle-induced cell-death rate (k<sub>max</sub>)**<br>
Units: h<sup>-1</sup><br>
