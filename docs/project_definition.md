# Aging Cell Targeting Simulator #

### Research Question ###

Which nanoparticle properties maximise selective uptake into senescent cells?

### Objectives ###
1. Model nanoparticle binding.
2. Model nanoparticle internalisation.
3. Model senescent cell clearance.
4. Investigate parameter sensitivity.
5. Compare hypothetical nanoparticle designs.

### Biological Processes Included ###
* Receptor binding
* Endocytosis

* Cell clearance

### Biological Processes Excluded ###
* Immune system interactions
* Drug metabolism
* Pharmacokinetics
* Tissue transport
* Machine learning approaches
